**_Custom STL Containers_**

This repository contains my implementation of various STL containers from scratch. The goal is to deeply understand the inner workings of the Standard Template Library (STL) by recreating its containers and key functionalities while adhering to C++ best practices.

_Implemented Containers & Features_

✅ Forward List (std::forward_list)

Singly linked list implementation with efficient insertion and deletion.

Supports all standard operations as described in cppreference.

✅ Graph (Adjacency List Representation)

Implementation of a graph using an adjacency list.

Includes basic graph operations like adding/removing nodes and edges.

Supports traversal algorithms such as DFS and BFS.

✅ Custom Allocators

Explored the concept of memory allocators in C++.

Implemented a custom allocator to manage dynamic memory efficiently.

🔄 Unordered Set (std::unordered_set) - In Progress

Implementing a hash-based container similar to std::unordered_set.

Utilizing hash functions, buckets, and collision resolution techniques.

Reference: cppreference.


_Motivation_

Gain an in-depth understanding of STL containers and their complexities.

Improve proficiency in C++ memory management and performance optimization.

Enhance problem-solving skills by implementing data structures from scratch.
